# 나만의 작업 공간

문서는 내 컴퓨터에 그대로 두고, 브라우저에서 편집하세요.

## 읽기와 편집

**굵은 글씨**, *기울임*, `인라인 코드`와 표를 확인해 보세요.

| 도구 | 하는 일 |
| --- | --- |
| 마크다운 편집기 | 로컬 문서 편집 |
| 프로필 생성기 | 인물 이미지 만들기 |
| 카드 미리보기 | 인물 카드 구성 |

> 오른쪽 위의 문서 테마를 바꾸면 읽기와 편집 화면에 함께 적용됩니다.

```js
const workspace = "내 로컬 폴더";
```
