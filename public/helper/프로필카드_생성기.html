상태 배지

사진 · 이모지

직접 이미지 주소를 입력하세요. CORS를 허용하는 서버의 이미지는 HTML에 포함되고, 그렇지 않은 이미지는 URL로 연결되어 인터넷 연결이 필요합니다.

선택한 사진은 복사·HTML 다운로드 시 보이는 영역만 작은 WebP 데이터로 HTML 안에 포함합니다. 같은 결과는 재사용합니다.

포함을 끄면 입력한 경로를 사용합니다. 브라우저는 전체 경로를 자동으로 읽을 수 없습니다. 경로 사진이 보이지 않으면 같은 파일을 위에서 선택하세요. 상대 경로는 Typora 문서 위치를 기준으로 합니다.

실시간 미리보기

도감의 ‘프로필 보기’는 같은 문서에 붙여 넣은 상세 카드로 이동합니다. 도감과 상세 카드의 앵커 ID를 같게 맞추세요.

Typora용 인라인 HTML

Typora에 코드 블록 없이 HTML 자체를 붙여 넣으세요. 테마에 따라 간격이나 글꼴이 달라질 수 있습니다. 작업 저장은 사진까지 포함한 편집용 JSON 파일입니다.
