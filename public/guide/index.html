initSimX 사용법

initSimX는 Markdown 편집기와 프로필 제작 도구를 한곳에서 제공하는 무료 웹 도구입니다. 문서와 사진은 내 PC에 두고 브라우저에서 작업할 수 있습니다.

내 PC의 Markdown 문서 편집하기

  1. 마크다운 편집기를 Chrome 또는 Edge에서 엽니다.
  2. 로컬 폴더 연결을 누르고 편집할 폴더를 선택한 뒤 브라우저의 폴더 접근 권한을 승인합니다.
  3. 폴더의 Markdown 파일을 열어 원문 편집, 시각 편집, 읽기 또는 분할 미리보기로 작업합니다. 문서 테마도 바꿀 수 있습니다.
  4. 내용은 입력을 멈춘 뒤 자동 저장됩니다. 파일을 수정하거나 삭제하기 전에는 같은 폴더의 `.initsimx-backups`에 백업을 만듭니다.

폴더 권한은 브라우저가 관리합니다. 브라우저나 사이트 설정에 따라 다시 연결 권한을 승인해야 할 수 있습니다. 원본 문서와 사진은 편집을 위해 사이트 서버에 업로드되지 않습니다. 중요한 문서는 별도 백업도 유지해 주세요.

프로필 이미지와 인물 카드 만들기

프로필 이미지 생성기에서 기기의 사진을 선택하거나 이미지 주소를 입력해 프로필 이미지를 구성하고 HTML로 내보낼 수 있습니다. 주소로 불러오는 이미지는 해당 이미지 서버의 접근 설정에 따라 미리보기나 내보내기가 제한될 수 있습니다.

프로필카드 생성기에서는 한 명 또는 여러 인물의 정보, 표시 필드, 배지, 사진이나 이모지를 구성하고 실시간 미리보기로 확인할 수 있습니다. 결과는 Typora 등에서 사용할 수 있는 인라인 HTML로 내보낼 수 있습니다.

파일과 개인정보 안내

편집기에서 선택한 로컬 폴더의 파일은 브라우저에서 처리하며, 저장·이름 변경·삭제와 내보내기는 사용자가 선택한 파일 작업에 따라 기기에서 이뤄집니다. 문의 폼에는 답변 이메일을 입력할 수 있고, 접수 내용은 문의 처리를 위해 저장됩니다. 자세한 정보는 개인정보 처리방침을 확인해 주세요.

자주 묻는 질문

모바일에서도 Markdown 편집기를 쓸 수 있나요?

폴더 연결과 파일 관리 기능은 현재 Chrome 또는 Edge 데스크톱 브라우저를 기준으로 제공됩니다. 로컬 폴더 접근 기능은 브라우저 지원 여부에 따라 달라집니다.

문서를 서버에 올려야 하나요?

아니요. 편집기에서 선택한 로컬 문서는 브라우저에서 처리합니다. 단, 사용자가 외부 이미지 주소를 입력하거나 문의 폼을 제출하는 경우 해당 요청에 필요한 정보는 각 서비스에 전달될 수 있습니다.

저장한 폴더를 다시 연결해야 하는 이유는 무엇인가요?

브라우저는 로컬 파일 접근 권한을 제어합니다. 권한이 유지되지 않았거나 다시 확인이 필요한 경우 편집기에서 폴더 연결 버튼을 눌러 승인하면 됩니다.
