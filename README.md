# initSimX Markdown Editor

사용자가 선택한 PC 폴더에서 Markdown 문서를 편집하는 정적 웹앱입니다. 개인용 Typora-Image-Upload와 분리한 프로젝트이며 Python 서버, 계정, DB, 업로드 API를 사용하지 않습니다.

## 개발 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

http://127.0.0.1:5173 에서 홈을 열고 **마크다운 편집기**로 이동하세요. 편집기 주소는 `/editor/`이며 Chrome 또는 Edge에서 **로컬 폴더 연결**을 누르면 됩니다. **예시 문서로 둘러보기**는 PC 파일 접근 없이 모드와 테마를 확인할 수 있습니다. 개발 서버는 정적 리소스만 제공합니다. 공개 서비스는 HTTPS가 필요합니다.

```sh
npm test
npm run build
```

Cloudflare Pages 배포 출력 폴더는 `dist`, 빌드 명령은 `npm run build`입니다. 도메인 루트 배포를 전제로 합니다.

## 기능

- 폴더의 Markdown 탐색, 파일·내용 검색, 생성, 이름 변경, 삭제
- 원본 소스 편집, Markdown 시각 편집, 읽기 및 분할 미리보기
- 입력 후 900ms 대기 후 자동 저장, SHA-256 기반 외부 변경 감지
- 수정·이름 변경·삭제 전 `.initsimx-backups/`에 사본 보관
- 브라우저가 권한을 유지하는 동안 저장된 폴더 핸들을 재사용하고, 필요하면 사용자 동작으로 다시 승인
- 편집 내용 내려받기, 미저장 변경 페이지 이탈 경고
- 선택 폴더 안의 상대경로 이미지와 HTTPS 이미지 미리보기
- 프로필 이미지·카드 생성기, HTML 내보내기, 카드 작업 JSON 저장/불러오기
- 생성기 사진을 브라우저에서 WebP로 변환해 내보낸 HTML에 포함

Markdown 편집은 원문을 표시하는 Vditor 편집 패널과 격리된 미리보기 패널로 구성됩니다. HTML 포함 문서도 원문을 편집할 수 있으며, 읽기·분할·편집 미리보기 모두 같은 Less 테마 CSS를 사용합니다. 앱의 헤더와 배경은 다크 스타일을 유지하고 문서 테마만 전환합니다. 미리보기는 스크립트 실행 권한 없는 sandbox iframe에서 표시합니다. 부모 화면이 스크롤 위치를 유지하도록 동일 출처 접근만 허용하며, 스크립트는 sandbox와 CSP로 차단합니다. 문서의 script·iframe·form 등 실행/삽입 요소는 미리보기에서 제외하지만 저장 원문은 변경하지 않습니다. HTTPS 이미지는 직접 미리보기하고, `http://init.n-e.kr:8081/Images/` 이미지는 제한된 Pages Function을 통해 미리보기합니다. 라이브러리는 자체 배포하고 분석 스크립트는 사용하지 않습니다.

## 검증과 제한

메모리 파일 핸들 테스트로 생성·저장·충돌·백업·이름 변경·삭제·경로 검증을 확인했습니다. 브라우저에서 홈·편집기·생성기 화면, Less 라이트/다크 적용, 읽기·소스·Markdown 편집·분할 보기, 소스와 편집 모드 사이 내용 반영, HTML 카드와 표 렌더링을 확인했습니다. 실제 OS 폴더 권한 승인부터 저장·재열기까지의 통합 테스트와 Typora 왕복 검증은 남아 있습니다.

폴더 핸들은 해당 브라우저의 IndexedDB에 저장합니다. Chrome/Edge가 권한을 유지하면 재방문 시 자동 연결되며, 권한 확인이 필요하면 사용자가 연결 버튼을 눌러 다시 승인해야 합니다. 연결 해제를 누르면 저장한 핸들을 지웁니다. 브라우저 정책에 따라 권한 재승인은 필요할 수 있습니다. 브라우저 종료 후 미저장 초안 복구, 오프라인 설치, 소스와 미리보기 스크롤 동기화는 아직 제공하지 않습니다. 백업은 자동 정리하지 않으며 사용자가 관리합니다. OS API가 원자적 비교 후 쓰기를 제공하지 않아 다른 프로그램과 정확히 동시에 저장하는 충돌까지 완전히 막을 수는 없습니다.

## 소스와 라이선스

개인용 프로젝트에서 편집 화면·생성기·문서 스타일을 가져왔으며 개인 문서와 이미지는 포함하지 않았습니다. Vditor와 하위 배포물의 라이선스는 `public/vendor/vditor/`에 보존했습니다. 프로젝트 자체의 공개 배포 라이선스는 아직 지정하지 않았습니다.

문서 테마 CSS는 기존 Typora 설치의 `less-light.css`, `less-dark.css`와 참조 CSS를 `public/themes/`에 합쳐 보관했습니다. 원본 라이선스가 해당 로컬 테마 폴더에서 확인되지 않아 공개 배포 전 Less 테마의 재배포 조건 확인이 필요합니다.
# Pages 배포

Cloudflare Pages에 `main` 브랜치를 연결해 정식 배포하고, `develop`은 미리보기 배포에 사용하는 계획입니다. 저장소의 Pages 설정은 다음과 같습니다.

- 빌드 명령: `npm run build`
- 출력 폴더: `dist`
- Cloudflare Pages 프로젝트 이름: `initsimx-markdown-editor`
- 직접 배포: `npm run deploy` (먼저 `npx wrangler login`으로 Cloudflare 인증)

Cloudflare Pages 프로젝트가 생성되어 있으며 운영 브랜치는 `main`입니다. 현재 배포는 Wrangler로 직접 업로드합니다. GitHub 연동 자동 배포는 아직 연결하지 않았습니다. `.pages.dev` 주소는 `https://initsimx-markdown-editor.pages.dev/`입니다.

GitHub 저장소의 기본 브랜치는 `main`이며 `develop`도 원격에 있습니다.

공개 배포 전에 `public/themes/less-light.css` 및 `less-dark.css`의 재배포 권리를 확인하세요. 이 파일은 로컬 Typora 테마 설치에서 가져왔고, 해당 설치 폴더에 라이선스 정보가 없습니다. Vditor와 번들 하위 라이브러리는 각 LICENSE 파일을 함께 포함합니다.
